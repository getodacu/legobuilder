# Geometry pipeline

Status: conversion/loading contract, not a report of implemented app assets. [Geometry research](../research/geometry-assets.md), [contextual LEGO crosswalk](../research/lego-part-crosswalk.md), and [VEX recovery](../research/vex-cad-recovery.md) are the evidence register. Root availability is not assembled-placement validation or manufacturer-certified historical mold equivalence.

## Adopt only the required, licensed closure

The authoritative LEGO crosswalk maps 132 build-context visual families to 64 selected LDraw roots. Those roots require 492 DAT dependencies; the expanded private research cache contains 561 inspected DATs including alternatives. Ship the selected closure, not an entire library or every cached candidate. Resolve by input + build + stable local key: the hand/head `azure-short-connector` keys select different geometry. Apply every documented source correction before authoring model instances. A geometry ID such as `2780.dat` is not a verified manufacturer design/element ID; unknown `partNumber` stays omitted.

Keep an immutable, hashed manifest per selected asset and dependency, retaining official raw URL, original path/header, authors, actual license declarations, history and modifications. Preserve both notices in mixed CC BY 2.0/4.0 files and attribution for dependency authors, not just root authors. Converted meshes must link to their exact source hashes and conversion settings. Bundle the applicable license texts, human-readable credits and machine-readable attribution with distributed assets; offer credits in the workspace. Original headers remain recorded even if binary geometry cannot carry comments. Attribution is not a substitute for a valid grant.

Do not ship `LDConfig.ldr` without its own established applicable permission. Use the small independently authored material table for the selected colors/material categories, with source-image/palette mapping evidence, no copied library material text or invented calibration. Inherited LDraw color 16 uses the instance material; fixed child colors stay fixed. Edge color 24 is handled by authored edge rules; explicit fixed colors remain visible. Electronics, decorated components and integral tires must not become uniformly tinted instance meshes.

## Coordinate and identity contract

Public `GeometryAsset.nativeToScene` is applied exactly once. Preserve each source-local origin, native hierarchy and mounting pivot; do not center each mesh on its bounds. A frame pose is already a scene-space millimeter pose. For LDraw, use `N = rotationX(π) × scale(0.4)` as the documented right-handed negative-Y-up to right-handed Y-up conversion. The 0.4 mm/LDU relation is approximate and is not metrology. Convert native part placements as `N × Tnative × N⁻¹`; keep root geometry conversion consistent with those converted instance poses. In Three.js column-vector convention, world geometry is `Tscene × N × pnative`, equivalent to `N × Tnative × pnative`. Never add a second root rotation/scale or reflect an axis to compensate visually.

Scene transforms serialize position xyz, normalized quaternion xyzw, scale xyz; ordinary instance scale is `[1,1,1]`. Asset-level conversion can have its documented uniform scale. Internal mirrored DAT references are handled inside conversion, including determinant/winding and BFC `INVERTNEXT`, not exported as guessed per-instance fixes. Record `CERTIFY`, `NOCERTIFY`, CW/CCW, clipping, nested transforms, type-2 edges and type-5 conditional edges. Do not make every mesh double-sided to conceal winding errors. A legitimate mirrored source subpart is distinct from a mirrored whole robot.

## Practical format routes

| Input | Adopted route and validation |
| --- | --- |
| DAT/LDR/MPD | Offline dependency resolution with deterministic case/path normalization and only allowed manifest dependencies; nested type-1 transforms, inherited/fixed colors, BFC, edges and MPD `FILE` sections preserved. Convert once to reusable mesh primitives or GLB; browser DAT loading is acceptable only for the narrow first slice and with the same curated closure. Never fetch arbitrary dependencies from a user-provided name. |
| glTF/GLB | Preferred ready-to-load runtime route after license checks. Preserve node names/pivots/material groups; glTF native meters require the declared mm conversion. Validate buffers, indices, normals, transforms and hashes. Do not silently flatten moving rotor nodes into the body. |
| STL | Authorized offline mesh import; STL units/materials are unspecified, so require explicit source-backed units/origin/frame and authored material assignment. Recover no nonexistent assembly hierarchy from one watertight body. |
| OBJ | Authorized offline import, declared units and frame, explicit group/material mapping; verify rights for MTL/textures independently. Keep mounting origin and normals, reject missing required resources. |
| STEP | Authorized offline tessellation with a real CAD kernel/tool, native product/occurrence names and placements retained, tessellation tolerance recorded. No STEP parser/kernel on the browser critical path. STEP BREP/placements do not establish joints, limits, procurement BOM or safe physics. |

VEX `historical2018` pairs the ©2018 manual 276-6009-750 Rev1 with the 2018-04-02 assembly CAD 276-6009-000 Rev1. Those revision namespaces are independent and exact manual/CAD equivalence is unverified. Native private STEP inspection has recovered frame/claw/motor geometry and internal occurrences. **No scoped CAD-to-app conversion/use permission is established, including for localhost development: do not tessellate, generate meshes, load app geometry or publish a fake substitute.** Keep the blocked catalog entry source-backed and mesh-free. Rev6 notch/wiring and the separate 2020 claw do not silently replace selected 2018 evidence. Permission plus revision/occurrence comparison are prerequisites, not optional final cleanup.

## Deep loader/cache module

`src/lib/geometry/cache.ts` implements the schema's `GeometryCache` interface. `acquire(asset)` resolves one validated asset and its declared dependencies, coalesces concurrent loads by source hash + conversion options, and returns a retained handle. The Three.js adapter extends the opaque `GeometryHandle` with renderer-owned buffer/material-slot data; UI and assembly engine never inspect it. `release(handle)` releases that acquisition exactly once. Shared resources stay alive while retained; failures do not create success handles. `dispose()` cancels pending adoption and releases remaining owned resources; a late completion cannot attach to a disposed viewer. Model switching uses a generation token so late model A results cannot replace model B. Do not add a general plugin framework or a cache server.

Cache key includes conversion version, source hash and material grouping policy, not only filename. Static geometry is immutable and shared. Repeated components use instancing per compatible geometry/material-slot/render-mode batch; the stable instance ID maps to batch/instance index for picking, highlighting and visibility. Multi-material fixed-color geometry can use multiple corresponding instanced primitive batches without duplicating the part identity/count. Selection outline and technical edges may have their own retained resources, not a rebuilt static mesh each frame. Internal moving motor nodes use verified asset nodes or an explicitly documented component decomposition, never duplicate inventory instances to simulate a rotor.

Resource ownership is explicit: the cache owns shared buffers, the renderer owns scene objects/instance matrices/mode materials/controls/resize observer, and the workspace owns the canvas/controller lifetime. A model unload releases its acquisitions; viewer disposal detaches listeners, stops render callbacks and disposes unshared GPU targets/materials. Geometry errors name the missing asset/dependency, preserve a readable error panel and block affected playback rather than render a box placeholder.

## Performance and validation obligations

Load only the chosen model and required assets; reuse geometry and material definitions across models where hashes match. Keep browser parsing, conversions and allocations off sampling. Update instance matrices/flags in existing buffers; bound pixel ratio and shadow/edge cost with renderer quality settings. Add mesh compression only after measured transfer/parse/memory evidence exceeds decode/dependency cost; no compression package by default. Do not merge away part picking or articulation to save draw calls.

Before claiming verified geometry, check dependency closure and hashes, per-file rights/attribution, source-origin invariance, scale/axis fixtures, mirrored BFC cases, inherited versus fixed colors, component-specific holes/axles/gears, asset bounds and retained articulation nodes. Compare representative source views with the assembled model separately: a valid mesh does not prove the correct hole, mold, insertion depth or whole-build pose. Performance numbers and device support must come from exercised implementation checks; none are asserted here.
