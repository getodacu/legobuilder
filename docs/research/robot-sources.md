# Robot source register

Research consolidated 2026-10-20. This register describes evidence, not completed robot models. The original five-build research set has inspected instruction sequences; **this research does not establish complete validated assembly transforms or calibrated physics**. Model-specific notes and JSON retain page-level evidence, hashes, quantities and unresolved identities. Downloaded manuals, native CAD and page images stay private in `.research-cache`.

**Authoritative current scope:** the user explicitly removed VEX V5 Clawbot. The active product contains exactly four LEGO builds: `advanced-driving-base`, `robotic-hand`, `quality-check` and `package-sorter`. VEX records below are historical source/license research, not a fifth model to complete or a rights gate before delivery. Original source counts remain unchanged. This scope change does not resolve remaining LEGO placement, calibration/retention, cable/port or Sorter pickup/routing acceptance; see [current coverage](../validation/coverage-baseline.md) for implementation and executable evidence.

## Reading the counts

A numbered instruction is not a PDF page, a prepared device is not its individually molded components, and a set's advertised element count is not a model BOM. The LEGO totals below are arithmetic sums of inspected new-parts callouts, **not manufacturer-published model counts**. Subassembly joins do not duplicate inventory; integral cables are counted with devices. Unknown catalog IDs remain unknown. VEX's printed list and step additions are two conflicting source records, not one reconciled BOM.

A palette is a layout of parts, not assembly transforms; [palette permission](https://www.johnholbrook.us/LDD_sets.html) does not license every external geometry dependency.

Its corrected names and build-specific geometry mappings supersede earlier descriptive labels without changing callout quantities. This resolves component shape availability, not historical-mold certification, routed cables or assembled placement.
